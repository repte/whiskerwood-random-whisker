# Random Whisker v0.1.0

First release for Windows, Whiskerwood 0.7.209.0 (game build of 16 October 2026).

- One HUD button spawns one random Whisker at the dock.
- Uses the game's own `Arco_SpawnAgentsAtDock` action; no runtime DLL.
- Hidden in menus, open windows and while saving.
- Tooltip in English and German.

Install: extract the `RandomWhisker` folder into `%LOCALAPPDATA%\Whiskerwood\Saved\mods\`.
Use either this local copy or the Workshop item, never both.

`SHA256SUMS.txt` lists the archive and package hashes.
